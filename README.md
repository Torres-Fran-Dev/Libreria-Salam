# 📚 Librería Salam - Plataforma Web Comercial

Plataforma web de catálogo e interfaz de gestión comercial diseñada para una librería local, con un diseño moderno, intuitivo y adaptado para ofrecer una experiencia de usuario fluida.

## 🚀 Enlaces
- **🌐 Ver página en vivo:** https://libreria-salam-libreriasalam.vercel.app/*
- **📦 Repositorio:** [https://github.com/Torres-Fran-Dev/Libreria-Salam](https://github.com/Torres-Fran-Dev/Libreria-Salam)

---

## ✨ Características Principales
- **Diseño Responsive:** Totalmente adaptado para visualizarse de forma óptima en celulares, tablets y computadoras de escritorio.
- **Catálogo Dinámico:** Visualización clara de productos, secciones y categorías orientadas al comercio minorista.
- **Interfaz Moderna:** Estilo visual limpio con componentes estéticos logrados mediante frameworks modernos de CSS.
- **Despliegue Continuo:** Hosting optimizado en la nube para garantizar velocidad de carga inmediata.

---

## 🛠️ Tecnologías Utilizadas
- **Frontend:** HTML5 (Estructura semántica), Tailwind CSS (Estilos y diseño responsivo)
- **Control de Versiones:** Git / GitHub
- **Hosting & Deploy:** Vercel (Producción continua)
